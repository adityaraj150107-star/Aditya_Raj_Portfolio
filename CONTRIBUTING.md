# Contributing to Aditya Raj's Portfolio

Thank you for taking an interest in this portfolio. Suggestions and improvements are welcome.

## Before making a change

- Keep the website responsive on desktop and mobile screens.
- Use semantic HTML and accessible labels for interactive elements.
- Keep CSS and JavaScript consistent with the existing project structure.
- Do not commit passwords, API keys, private contact information, or other secrets.

## How to suggest an improvement

1. Open an issue describing the problem or improvement.
2. For a code change, create a focused branch from `main`.
3. Test the page in a browser at desktop and mobile widths.
4. Submit a pull request with a clear summary and testing notes.

## Local preview

From the repository folder, run:

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000` in your browser and stop the server with `Ctrl+C` when finished.
