# Security Policy

## Reporting a security issue

If you find a security issue in this portfolio, please avoid posting sensitive details publicly. Contact the repository owner through the email address listed in the portfolio and include:

- A short description of the issue
- Steps to reproduce it, if safe to share
- The page or file affected
- Any suggested mitigation

Please do not include passwords, access tokens, or other secrets in reports.

## Scope

This repository is a static HTML, CSS, and JavaScript portfolio. Do not submit real personal data or secrets as test content. Security reports are reviewed as time and availability permit; no response-time guarantee is implied.
